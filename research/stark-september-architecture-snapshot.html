Stark is being built as a local-first digital being rather than a single chat model. M0–M7 produced a frozen neural language substrate. M8 then added the first promoted Stark-native memory organ while keeping that language substrate byte-identical.

Founder is still an organ, not the organism. M8 makes the same statement true of memory: SFM-1 is a specialized memory organ, not a reasoning engine.

What M8 established

M8 separated several concepts that large monolithic models often blur together:

  • memory machinery != remembered knowledge — SFM-1 core weights define how memory operates; persistent state contains accumulated facts;
  • neural association != exact truth — semantic state selects a fact_id; exact payload and provenance are resolved from an independently integrity-bound exact-memory substrate;
  • retrieval != reasoning — SFM-T may expose several memories, but it does not choose a winner or decide applicability;
  • READ != LEARN — ordinary use does not automatically acquire, reinforce, consolidate, or backpropagate;
  • causal delivery != reliable utilization — M8.10 proved memory reaches Founder, while M8.11 showed that the weak V0 language substrate does not yet use memory reliably enough to produce exact answers.

Promoted after M8.12

The M8 promotion review accepts:

  • SFM-1 semantic memory;
  • exact-memory architecture;
  • SFM-T as a deterministic retrieval-breadth mechanism;
  • typed Global Workspace memory request/candidate/context contracts.

FounderV0CompatibilityBridge v1 remains an accepted research baseline, not a final neural workspace interface. It proved causal connectivity but also introduced interference and weak exact-answer utilization.

The new bottleneck

M8.11 found that correct single-memory context improved Founder's target distribution on 467/512 cases (91.21%), but exact answer generation was 0/64, irrelevant memory degraded target probability on median, and neighborhood memory was negative on average in the tested four-candidate ordering.

The next unresolved problem is therefore not durable factual storage. It is selective cognitive interpretation and use of retrieved memory.

That result informs M9, but it does not define M9 in advance. The next milestone should be designed from a fresh research question rather than retrofitting a predetermined mechanism.

Long-term direction

The broader Stark design can still grow through specialized cells and heterogeneous mechanisms. Future regions may use exact local attention, recurrent state, state-space processing, retrieval, semantic memory, exact discrete memory, or other mechanisms where each is appropriate.

The constraint remains experimental discipline: one measurable architectural claim at a time, with fail-closed promotion and preserved failed evidence.

Governance remains non-negotiable

Persistent memory and later continual learning increase capability and risk together. Permission boundaries, rollback, explainability, recoverability, and provenance remain architectural constraints rather than optional interface features.
