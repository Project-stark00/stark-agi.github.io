# STARK.md

Public website conventions for StarkAGI.

- Vanilla HTML, CSS and JavaScript only.
- Research content lives in `articles/*.md` and is indexed by `data/articles.json`.
- Progress lives in `data/progress.json`.
- Publish measured failures alongside successes.
- Do not describe a capability as accepted unless its actual acceptance gate passed.
- Founder V0 is the immutable M7 baseline; descendants should be named separately and compared against it.
